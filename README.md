### Installation

1. Clone the repository
   ```js
   git clone https://github.com/wali39/Instant-group-creator.git
   ```
2. Install dependencies

   ```sh
   yarn
   ```

3. Setup Environment variable `.env`

   ```js
   REACT_APP_API_URL = "put your instant group creator backend url";
   ```

4. Run development server

   ```js
   yarn start
   ```
